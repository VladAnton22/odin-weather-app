# Weather App ☀️🌧️

A client-side weather application built with vanilla JavaScript as part of **The Odin Project** curriculum.

The app fetches real-time weather data from the Visual Crossing Weather API and displays current conditions based on user search input. The main focus of this project was working with asynchronous JavaScript, API consumption, and handling external data.

---

## Features

- Search weather by city or location
- Fetch real-time weather data from an external API
- Display current weather conditions
- Error handling for invalid locations
- Clean and responsive UI

---

## Tech Stack

- **JavaScript:** Vanilla ES6+
- **API:** Visual Crossing Weather API
- **Styling:** CSS (or minimal utility styling)
- **Async Handling:** Fetch API & Promises

---

## How It Works

- User enters a location
- The app sends a request to the Visual Crossing API
- Weather data is fetched asynchronously
- Relevant weather information is displayed in the UI
- Errors are handled gracefully for invalid searches
